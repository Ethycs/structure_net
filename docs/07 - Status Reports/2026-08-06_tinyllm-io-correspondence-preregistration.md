# TinyLLM gauge-repaired I/O correspondence test — preregistration

**Status:** PREREGISTERED before target-side training or I/O-map analysis

**Date:** 2026-08-06

**Hypothesis:** `tinyllm-io-correspondence-gauge-descent-v1`

## Question

Does repairing the observation gauge—either by refining the observation with a
phase-independent calibration reference or by replacing the target with a
gauge-invariant relative coordinate—turn the paired relation

```text
X <- Gamma_T -> Q_T
```

into a stable interval quotient realized through TinyLLM's layers on held-out
composition and outside-range extrapolation?

The reference object is the paired I/O relation with both projections retained,
not the homology of a concatenated `(x, y)` point cloud.

## Prior-outcome boundary

The calibrated absolute-cosine campaign has already been inspected. Its 15
cells are frozen positive-control evidence and may be reused only after their
checkpoint, architecture, initialization, data, minibatch, and implementation
digests pass. Their previously reported base/fiber endpoints are not new
confirmatory outcomes.

The uncalibrated campaign cannot be reused: it used a 26-position transformer
context and a different initial-model digest. Four uncalibrated arms are trained
from scratch in the common 27-position configuration. All layerwise Mapper and
paired-distortion measurements are new and were not inspected before this
preregistration.

## Conditions and arms

| I/O relation | Observation | Target | Arms |
| --- | --- | --- | --- |
| uncalibrated absolute | `O(z)` | `cos(phi)` | raw; learned equivariant |
| calibrated absolute | `(O(z), c(z))` | `cos(phi)` | raw; analytic canonicalizer; learned calibrated-equivariant |
| uncalibrated relative | `O(z)` | `cos(phi + theta)` | raw; learned equivariant |

Here `theta` is the sensor-orientation nuisance. Under the exact gauge action
`phi -> phi + alpha`, `theta -> theta - alpha`, the relative coordinate is
unchanged. It is encoded in the sensor-frame trajectory and uses no latent or
target side channel.

The calibration packet is the prior phase-independent pilot record: orientation
vector, signed speed, amplitude, planar offset, and planar drift. It contains no
phase, branch, harmonic phase, target cosine, or task label.

## Data-level descent contract

Before any model result is interpreted, exhaustive exact gauge pairs must show:

```text
uncalibrated absolute: x = x' with y != y' exists (deliberate failure)
calibrated absolute:   x = x' implies y = y'
uncalibrated relative: x = x' implies y = y'
```

The numerical audit is accompanied by the symbolic identities
`O(phi, theta) = O(phi + alpha, theta - alpha)` and
`cos(phi + theta) = cos((phi + alpha) + (theta - alpha))`.
Equality refers to observation distributions; arbitrary cancellation by a
particular additive-noise realization is outside the latent-state contract.

## Fixed training design

- d8 TinyLLM; common block size `sensor sequence length + 1`;
- seeds 7, 17, 29, 41, and 53;
- N3, 4,096 shared latent trajectories and nuisance draws per seed;
- batch size 64, 600 updates, AdamW `3e-4`, weight decay `0.01`, clip `1.0`;
- ordinary 16-bin interval task cross-entropy only;
- identical transformer initialization, examples, and minibatch schedule within
  each matched seed;
- one fixed zero context token in uncalibrated raw arms so every transformer has
  the same positional capacity as calibrated raw;
- learned uncalibrated front end: shared planar temporal channels with
  trend/scale removal and an SO(2)-equivariant vector readout;
- learned calibrated front end: reference-corrected equivariant vector mixing,
  followed by dot/cross invariants with the observed orientation;
- analytic canonicalizer only in the calibrated condition.

The 15 calibrated cells may point to their immutable source checkpoints. The 20
new cells retain their own transformer and front-end weights.

## Evaluation cohorts

Training, probe training, probe validation, and test cohorts are disjoint.
Within a relation, exact fiber cohorts are generated by fixing the target cosine
and pairing its two phase branches under independent nuisance draws. A shared
latent/nuisance cohort is also retained for direct cross-relation comparison.

Evaluation families are in-distribution N3, held-out nuisance composition, and
outside-range extrapolation, using the generator definitions already frozen by
the nuisance-support campaign.

## Primary base/fiber endpoint

At front-end output, post-attention block 1, post-MLP block 1, and full depth,
fit fresh nonlinear frozen-representation probes. The branch probe is explicitly
conditioned on the relation's target cosine.

A cell passes when all hold:

```text
corr(y_hat, y) >= 0.90
balanced_accuracy(branch | R, y) <= 0.55
conditional_log_loss_gain_over_y_only <= 0.02
```

A seed passes an arm only if every cut passes on both composition and
extrapolation. An arm succeeds in at least four of five seeds.

The decisive prediction is:

- calibrated analytic and calibrated learned succeed;
- uncalibrated relative learned succeeds;
- uncalibrated absolute learned fails globally, specifically on extrapolation;
- raw arms are matched information/function-class controls and are reported but
  are not required to form a quotient.

For each repaired learned arm, mean exact-bin task accuracy on each primary
shift must not trail its matched raw arm by more than three percentage points.

## Target-lens Mapper diagnostic

For each cut and primary shift, use target cosine as the lens. Standardize
features by the probe-train statistics, retain at most 16 unsupervised principal
components, and use nine equal-width cover intervals with 30% overlap. Within
each pullback cover, construct a symmetric 12-nearest-neighbor graph. Connected
components with at least four samples are Mapper nodes; overlapping nodes share
an edge when they contain a common sample.

Report node count, connected components, graph cycle rank, sample coverage,
interior single-sheet fraction, and interior two-branch-sheet fraction. The
predeclared interval-like diagnostic is at least 75% single-sheet interior
covers, at least 90% sample coverage, one connected Mapper component, and cycle
rank zero. This is a mechanistic diagnostic and cannot rescue a failed primary
base/fiber endpoint.

## Paired-map distortion

For each exact fiber pair, average its two representations. Estimate a diagonal
fiber-residual whitening scale from the within-pair differences, with a fixed
`1e-3` relative floor. Compare all paired target distances with all whitened
fiber-centroid distances after normalizing each by its 95th percentile:

```text
D_l = median |d_Q_tilde(y_i, y_j) - d_l_task_tilde(mu_i, mu_j)|.
```

Also report standardized Euclidean and cosine-distance controls and Spearman
distance-order correlation. These are secondary continuous measurements; no
post-outcome distortion threshold determines confirmation.

## Outcome meanings

| Result | Interpretation |
| --- | --- |
| both repaired learned arms pass | observation refinement and target quotienting both restore descent-compatible quotient realization |
| calibrated passes, relative fails | the chosen target-side quotient or its equivariant readout is inadequate |
| relative passes, calibrated fails | the calibration channel/canonicalizer is operationally inadequate despite abstract identifiability |
| neither repaired arm passes | impossibility is repaired, but approximation or optimization remains inadequate |
| base passes without fiber | a decoder exists, but the representation retains a phase cover |
| fiber passes without base | compression occurred, not a semantic quotient |

## Amendment A — corrected equivariant output contract

**Timing:** added after the original 35-cell artifact completed and after the
learned-relative primary metrics had been seen.

**Original artifact:**
`data/experiments/tinyllm_io_correspondence/20260806_d8_preregistered/`

The first implementation imported `LearnedEquivariantEncoder.forward`, which
returns only the x-component of an internally equivariant planar vector. A
single coordinate is not an SO(2)-equivariant representation and therefore did
not implement the declared “equivariant vector readout” in either uncalibrated
learned arm. The completed artifact is preserved, but its learned-uncalibrated
cells cannot decide the preregistered architectural claim. Raw and calibrated
cells remain valid measurements of their named systems.

The correction exposes the complete normalized two-dimensional equivariant
vector and embeds both coordinates into the same single transformer token. An
exact rotation contract is added:

```text
E(R_alpha x) = R_alpha E(x).
```

No data, target, optimizer, update count, seed, probe, Mapper, distortion, or
decision threshold changes. The correction uses a new schema, producing runner,
and append-only artifact root:

- runner: `experiments/structure_net/tinyllm_io_correspondence_v2.py`;
- schema: `nal.tinyllm-io-correspondence.v1.1`;
- root: `data/experiments/tinyllm_io_correspondence/20260806_d8_corrected_equivariant/`.

Because this correction follows inspection of affected outcomes, its learned
uncalibrated result is reported as a disclosed implementation correction, not
as pristine preregistered confirmation. The original outcome remains visible
and is not pooled with the corrected cells.
