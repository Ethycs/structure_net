## Question

Three causal continuation audits show that an orbit-local task tangent repairs
the failed quotient writer, but one fixed metric is not stable across support.
Before evaluating another activation family, test the necessary algebraic
condition for symmetry transport:

> Does the current three-coordinate order-four quotient writer carry an
> induced representation of the exact cyclic task-phase group?

If not, transporting its local covectors through that writer is ill posed:
the phase group sends allowed coordinate writes outside the writer's
three-dimensional image.

This study loads stored writer matrices only. It trains no model, writer,
probe, decoder, map, or observer and performs no CUDA continuation.

## Declared group representation

The order-four feature row is

```text
Phi(theta) = [cos theta, sin theta, ..., cos 4 theta, sin 4 theta, 1].
```

Use the exact cyclic output-bin group `C16`, generated by
`alpha = 2 pi / 16`. For row-vector convention,

```text
Phi(theta + alpha) = Phi(theta) A,
```

where harmonic `m` has the fixed block

```text
[[ cos(m alpha),  sin(m alpha)],
 [-sin(m alpha),  cos(m alpha)]]
```

and the constant channel is fixed. Verify `A^16 = I` numerically before using
any writer result.

Let the stored writer be `W in R^(9 x 3)`, so the coordinate write is
`c = Phi W`. A three-dimensional coordinate action `R` exists only if

```text
A W = W R.
```

Let `P_W = W W^+` and define the basis-independent obstruction for every
nonidentity group element:

```text
epsilon_q = ||(I - P_W) A^q W||_F / ||A^q W||_F,
q = 1, ..., 15.
```

Record the maximum and RMS obstruction. Define the least-squares induced
generator

```text
R = W^+ A W
```

and its closure error

```text
epsilon_close = ||R^16 - I_3||_F / sqrt(3).
```

Also record writer singular values, condition number, and overlap with the
four canonical invariant three-dimensional subspaces
`span(cos(m theta), sin(m theta), 1)` for `m=1,...,4`.

## Controls

1. **Feature representation:** `||A^16-I_9||_F/sqrt(9) <= 1e-12`.
2. **Identity action:** the `q=0` subspace obstruction is at most `1e-12`.
3. **Canonical subspaces:** all four declared harmonic-plus-constant
   subspaces have maximum `C16` obstruction and induced closure at most
   `1e-12`.
4. **Random-subspace specificity:** generate 256 deterministic Gaussian
   rank-three subspaces per checkpoint, orthonormalized by QR. The writer's
   maximum orbit obstruction must be below the fifth percentile of the
   matched random distribution.

Random controls are seeded only by checkpoint identity and are fixed before
evaluation. They cannot rescue a failed absolute intertwiner threshold.

## Primary gate

A checkpoint passes the `C16` writer-intertwiner gate only when:

- every provenance and control contract passes;
- `W` is finite and has numerical rank three;
- maximum orbit obstruction is at most `0.05`;
- induced closure error is at most `0.05`; and
- random-subspace specificity passes.

The hypothesis is supported only if all `3/3` checkpoints pass. The `0.05`
limits are approximation gates, not exact-representation claims.
