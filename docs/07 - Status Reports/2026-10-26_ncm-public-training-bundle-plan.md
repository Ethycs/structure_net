completed/audited full FP32 feature store and completed/audited full codec
targets into one immutable training-input manifest. Both GPU producers are
still running when this plan is specified. No partial store or smaller subset
is admitted by this entry point.

Require actual exit-zero receipts for both full producers and both subsequent
CPU audits. Require the same 162,353 original catalog identities and ordered
source/target/native-frame bindings, 91,344,717 complete source positions,
the original body hash and fixed repaired codec hash. Verify every feature
header against the source metadata record, original prompt/alignment hashes,
source length and FP32 shape. Verify the complete ordered code target index
against each original reference/native frame. Require every recorded shard
to exist at its declared size. Preserve the original 320 public development
reservation and application protection manifest.

admission uses its actual receipt and hash-bound result, then checks all
indexes and headers; it does not perform another corpus-wide GPU extraction
or read all feature payloads into RAM. The training Dataset verifies each
requested compressed payload and reconstructed FP32 hash before returning it.
Catalog/code JSONL reads remain individually hash-bound. Hash all evidence,
input indexes and loader sources in the bundle. No user-visible metric is
renamed to accuracy: these are training inputs, not quality results.

cwd through locked Pixi `ncm`. The manifest may then open a disk Dataset after
