# Semantic evaluation of trained source attention hierarchies

Evaluate the fixed final tree and dense checkpoints from the matched source
hierarchy comparison. Every NCM generator block reads the source; tree adds
pooled ancestor levels while preserving the token leaves. The trainable
populations differ, so the result tests the complete added mechanism.

Require successful terminal training and independent exposure audits before
loading each arm. Reconstruct its architecture before strict state loading;
verify the exact full model and frozen reconstruction hashes. Use physical
GPU1 RTX2060, FP32 inference, unchanged native BERT rendering, and the fixed
128 source-only DEV cases. Source features are cached frozen-body features;
the reported memory excludes a live Llama encoder. The decoder being trained
separately is never installed in either arm.

Preserve all completed public and existing/expanded task-supervision first
judgments. Evaluate tree before dense. Each arm freezes its inherited history
at preflight; later changes require an explicit lineage extension, never a
silent reset. Run repeated two-case inference, full128 inference, the four
qualified Terra judge pilot decisions, full grading, and raw semantic replay.
Reuse the established cohort gates and Sol confirmation rules. Full-summary
semantic passes out of128 are the task metric. Codec exact matches and training
loss are not application accuracy. Final320 remains sealed.

The shared semantic audit is consumed through a process-local interface; no
existing training or evaluation producer source is changed. Keep the existing
semantic artifact schema and record the new hierarchy hypothesis and arm.
Focused tests must reject the wrong architecture, incomplete exposure, and
changed checkpoints, and exercise strict state loading on both real mechanism
classes after their added branches have nonzero weights.

This is quality evaluation. Training duration and cached-feature memory cannot
establish end-to-end inference speed. A speed comparison remains a separate
measurement after quality is known.
