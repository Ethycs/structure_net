# Reuse measured hashes within future semantic evaluation processes

The unchanged existing-arm judge pilot completed with four valid judgments and
four failures. Its original producer remains unchanged. Before sending those
requests, its validation process read more than 27 GB; observed open files were
completed training checkpoints. The shared artifact helper hashes the same files
again when several receipts bind them.

For future, not-yet-started semantic stages, use the already tested process-local
hash implementation from recovered training. Every process, including each
independent audit, starts empty and reads every first-seen file in full. Only
unchanged files of at least 1 MiB and older than two seconds may reuse that
locally measured hash. Check device, inode, size, modification time and change
time on every reuse. Rehash small or recently written files. Reject changes
during hashing and check every requested expected digest as before.

Run the existing three cache tests and the new semantic-binding contract before
launch. Bind this policy and qualification into each new producer. Preserve the
same artifact roots for stages that have never started, all prior first judgments,
model and source hashes, judge admissions, rubric, packet identities, retry
budgets and decision order. The policy changes input verification work only;
it does not alter NCM computation, checkpoint selection or judge responses.
Any runtime benefit is workflow overhead, not an NCM token-throughput result.
