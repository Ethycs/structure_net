# TinyLLM stable-defect subspace rank titration preregistration

**Status:** PREREGISTERED — PRIMARY OUTCOMES NOT INSPECTED  
**Date:** 2026-08-06  
**Conformance:** NAL-STD-EXPERIMENT `PREREGISTERED`  
**Hypothesis:** `tinyllm-c2-defect-subspace-rank-v1`  
**Schema:** `nal.tinyllm-defect-subspace-rank.v1`

## Question

The stable degree-two quotient front is distributed across four or more
attention heads. Does that coalition nevertheless write one shared activation
direction, or is the causal Reynolds defect genuinely multidimensional?

## Frozen scope

Use only the three cross-cohort-stable block-0 attention checkpoints: seeds 7,
29, and 53. Reuse their frozen d6 models and exact degree-two orbit generator.
No model training, observer fitting, label use, or parameter update is allowed.
One independently initialized checkpoint is the replication unit. This is a
three-seed mechanistic follow-up to an independently established stable-front
cohort, not a new five-seed population claim.

## Design, controls, and splits

| Field | Frozen policy |
| --- | --- |
| intervention | rank of the source-defect right-singular projection |
| architecture and weights | unchanged d6/N3 TinyLLM checkpoints |
| source cut | exact first block-0 post-attention synthesis cut |
| source examples | 64 exact `C2` orbits per shift |
| held-out examples | two disjoint 64-orbit cohorts per shift |
| downstream computation | unchanged frozen continuation and decoder |
| optimizer / updates | none |
| model seeds | `7,29,53` |
| evaluation seed policy | checkpoint seed plus fixed cohort/shift offsets |

The exact cohort seeds are inherited from the audited head-decomposition
protocol:

| Cohort | Offset and shift stride | Role |
| --- | ---: | --- |
| source selection | `+2501 + 101 * regime_index` | fit SVD basis only |
| held-out A | `+4501 + 101 * regime_index` | frozen evaluation |
| held-out B | `+9101 + 307 * regime_index` | frozen evaluation |

Composition and extrapolation are generated by the existing exact-orbit task
generator and concatenated only within the source basis fit. No held-out state,
posterior, task label, or gate may influence the basis or rank-one primary
claim.

For each checkpoint, form the exact attention Reynolds defect

```text
D(x) = mean_j F(h_j(x)) - F(mean_j h_j(x)).
```

Fit one checkpoint-local right-singular basis to `D` from the declared source
cohort, concatenating composition and extrapolation before the SVD. The same
basis and rank must then be used without reselection on two untouched cohorts
under both shifts.

The available source span is the numerical SVD row space using relative
singular-value tolerance `1e-10`; numerical null directions are excluded.

## Causal interventions

Flatten only token and channel axes. For ranks `1, 2, 4, 8, 16, 32, 64` and
the complete available source span, patch

```text
propagated barycenter + D_test V_r^T V_r
```

at the frozen post-attention cut. Also patch the exact full defect, no defect,
the rank-1 orthogonal complement, and a deterministic random rank-1 direction
drawn inside the same source span.
Continue every state through the unchanged downstream model.

The projection uses the exact test-cell defect and therefore tests causal
representational sufficiency, not whether the model can independently compute
that projection.

## Primary endpoint

A rank is sufficient in a held-out cell only when it passes the frozen causal
task conjunction and preserves at least `0.90` of the exact downstream Fisher
effect. The primary scalar-mechanism hypothesis requires rank 1 to be
sufficient in all four held-out cohort/shift cells for all three checkpoints.

The rank-1 complement must preserve at most `0.50` of the effect in every cell,
and the deterministic random rank-1 control must not meet the sufficiency
endpoint. Exact full-defect patches must pass and zero-defect patches must fail
in every held-out cell.

All five contracts—orthonormal/numerical-rank basis, exact endpoint
replication, rank-one sufficiency, weak rank-one complement, and random
source-span specificity—must pass independently in all three checkpoints.
Secondary ranks cannot rescue a failed rank-one hypothesis.

## Secondary endpoint

If rank 1 fails, report the smallest fixed rank sufficient across all four
held-out cells for each checkpoint. Do not promote a rank selected separately
per shift or cohort. Report source singular-energy curves, held-out Fisher
preservation, task gates, and source-span transfer failures.

## Interpretation

- Rank 1 sufficient and complement weak: distributed heads coordinate a
  scalar invariant write direction.
- A small rank above 1 sufficient: the coalition writes a low-dimensional but
  genuinely vector-valued invariant carrier.
- Only a large rank or exact defect succeeds: decoder-relevant synthesis is
  high-dimensional despite the quotient target.
- Source span fails: the causal defect subspace itself is support-relative.

## Exclusions, retries, and amendments

invalidates the cell and must remain visible rather than being silently

## Method boundaries

The SVD is geometric rather than task-weighted. Held-out patches use the exact
held-out defect and therefore test representation-level sufficiency, not
whether a new module can compute that projection from raw input. Bases and
head coordinates are checkpoint-local. All Fisher and task endpoints remain
conditioned on the frozen downstream decoder, and projected states may be off
the natural activation manifold.

## Amendment A — post-outcome power-profile clarification

Recorded on 2026-08-06 after the primary outcomes were inspected. NAL-STD-
EXPERIMENT section 3.3 requires a campaign with fewer than five independent
seeds to be labeled `UNDERPOWERED`. The design already fixed the three
independently trained checkpoints whose stable fronts had been established by
prior cohorts, but the header did not use that exact label. This amendment
adds no seed, endpoint, threshold, exclusion, or interpretation and does not
alter the original analysis. The report treats all results as an underpowered
mechanistic cohort claim and makes no five-seed population claim.
