## Question and scope

Does a natively trained 2048-context member of the frozen TinyLLM model family
retain A7's normalization-faithful chronological H2 representation and become
cheaper than dense causal attention at long context?

This is an A7 replication-and-scaling study on one new checkpoint. It is not a
positional extension of the original 256-context checkpoint and it does not
measure variation across trained-model seeds. Dense operator construction is
permitted: the study tests oracle representation and theoretical application
cost, not implicit construction or wall-clock speed.


The tokenizer, flattened corpus order, final 262,144-token validation suffix,
and NumPy PCG64 uniform-start sampling procedure are identical to the original
pretraining campaign. Three consecutive microbatches are averaged before each
optimizer update. This gives `3 * 2048 = 24 * 256 = 6144` target tokens per
update and exactly matches the original 12,000-update token budget.

Checkpointing and exact resume may save optimizer, scaler, NumPy generator,
and CPU/CUDA RNG states; checkpoint cadence is a systems property and cannot
change the learning-rate or sampling coordinates.

## Model-competence gate

After training, evaluate both the original checkpoint and native-2048
checkpoint on the exact same 384 validation windows of length 256: 16 batches
of 24 windows generated by `numpy.random.default_rng((7, 424243))` under the
original sampling rule. Also report native-model loss on 48 length-2048
windows (16 effective batches of 3) from a separately reset generator with the
same seed tuple. All losses are token-mean cross entropy.

The model-competence gate passes exactly when both losses are finite and

```text
(native_loss_256 - original_loss_256) / original_loss_256 <= 0.05.
```

Failure prevents interpretation of any H2 crossover and receives the dedicated
classification below.

## Evaluation population and nested-prefix lock


five seeds are input-selection replicates on one trained checkpoint, not model

## Numerical and representation gates

A cell's `representation_pass` is A7's conjunction of its complete validity
contract and six scientific gates:

| Endpoint | Gate |
| --- | ---: |
| stabilized-kernel attention versus model softmax | `<= 1e-12` max absolute |
| basis orthogonality | `<= 1e-10` spectral residual |
| parent-child nestedness | `<= 1e-10` relative residual |
| explicit versus contracted H2 matvec | `<= 1e-10` relative error |
| future-token leakage | `< 1e-15` |
| weighted row-relative kernel error | `<= 0.01` |
| denominator relative error | `<= 0.01` and positive |
| attention row L1 error | `<= 0.025` |
| probe relative Frobenius error | `<= 0.02` |
| value-output relative Frobenius error | `<= 0.02` |
| p99 token error / global output RMS | `<= 0.05` |

The short-context replication gate requires representation-pass fraction at
least 0.80 independently at 64, 128, and 256. Long-context representation is
considered retained only when the fraction is at least 0.80 independently at
512, 1024, and 2048.

## Primary crossover endpoint

A cell is useful at length `n` exactly when it passes representation and both

```text
stored_H2_scalars / dense_causal_scalars < 1
H2_multiply_adds / dense_causal_multiply_adds < 1.
```

The crossover passes only when useful-cell fraction is at least 0.80 at both
1024 and 2048 and every layer has useful-cell fraction at least 0.50 at both
lengths.

## Required diagnostics

For every length report storage and operation ratios and their decomposition
into near, leaf, transfer, and coupling costs; maximum node rank; node-size
weighted mean rank

```text
sum_node(size(node) * rank(node)) / sum_node(size(node))
```

over both query and key families; admissible coupling count divided by length;
near-field share of total H2 storage and operations; rank-cap hits; mean causal
attention-row entropy; and standard deviation of finite causal logits.

For each cell fit descriptive log-log least-squares exponents over all six
lengths for total H2 storage, total H2 operations, and weighted rank. Aggregate
their median and 90th percentile. These exponents are descriptive, not
asymptotic proofs. Compare the new checkpoint's short-length ranks, costs, and
per-layer pass fractions descriptively with A7; do not splice the curves.

## Classification order

1. `invalid_native_long_context_contract` if training provenance, partition,
   or any numerical validity condition fails.
2. `native_long_context_model_competence_failed` if the competence gate fails.
3. `native_long_context_a7_replication_failed` if any short length is below
   80% representation pass.
4. `native_long_context_h2_scaling_failed` if any long length is below 80%
   representation pass.
5. `native_long_context_h2_crossover_pass` if both long crossover and layer
   coverage rules pass.
6. `native_long_context_h2_layer_selective_crossover` if at least one cell at
   1024 or 2048 is useful but the campaign crossover rule fails.
7. `native_long_context_h2_representation_only` otherwise.

Training loss, theoretical counts, or favorable individual heads cannot rescue
an earlier failed gate. A single-checkpoint result must retain the limitation
that trained-model variability is unmeasured.
